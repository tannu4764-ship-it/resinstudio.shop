# My Resin Studio — Handcrafted Resin Art & Personalised Gifts

Official website for **My Resin Studio**, a handcrafted resin art studio based in Govind Nagar, Kanpur (PIN: 208006).

## 🌸 About the Business
My Resin Studio creates bespoke handcrafted resin products, personalised gifts, custom family entrance nameplates, aesthetic home décor, and wedding garland (*varmala*) floral memory preservation blocks for customers across Kanpur (Govind Nagar, Barra, Gujaini, Kidwai Nagar, Kakadeo, and surrounding areas).
